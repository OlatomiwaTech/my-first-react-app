# React Frontend Development Course

A practical React learning course focused on understanding React fundamentals and using them to build real frontend interfaces.

## Course Goal

The goal of this course is to understand the fundamentals of React well enough to build, modify, debug, and explain frontend applications independently.

By the end of this course, I should be able to:

* Build React components from scratch
* Understand and use JSX
* Pass data using props
* Manage UI state with `useState`
* Handle user interactions and events
* Render lists and conditional UI
* Work with forms
* Use `useEffect`
* Fetch and display API data
* Build multi-page applications with React Router
* Structure a frontend project cleanly
* Understand existing React code instead of blindly modifying it with AI

# AI Usage Rules

AI can be used as a learning and development assistant, but it must not replace understanding.

### Allowed

* Explaining React concepts
* Explaining unfamiliar code
* Debugging errors
* Suggesting improvements
* Reviewing code
* Helping with difficult implementation problems

### Avoid

* Generating an entire application without understanding it
* Copying code that cannot be explained
* Using AI for every small problem
* Merging AI-generated code without testing it

### Rule

For every significant AI-generated change, I should be able to explain:

1. What changed?
2. Why was it changed?
3. Which component owns the state?
4. What causes the component to re-render?
5. How does the data move through the application?
